# Agent X — Autonomous Trading Intelligence

> ⚠ **School Project** — This is an academic project, not a real financial service or investment platform.

## Overview

**Agent X** is a fictional SaaS product concept for an AI-powered autonomous trading platform. This landing page demonstrates a professional product website as part of a school project exploring:

- SaaS product design and UX
- Modern web development (responsive design, animations, accessibility)
- Product positioning and pricing strategy
- AI in financial technology

## Features (Conceptual)

The landing page showcases these fictional product features:

- **Autonomous Trading Bots** — AI agents that execute strategies 24/7
- **Multi-Account Bridge** — Unified management of FTMO, demo, and live accounts
- **Smart Risk Management** — Hard-enforced risk limits and drawdown protection
- **Real Backtesting Engine** — Strategy validation with live broker data
- **News-Aware Decisions** — ForexFactory calendar integration
- **Self-Healing Watchdog** — Automatic infrastructure recovery

## Tech Stack

- **Single HTML file** — Zero build step, no framework dependencies
- **CSS** — Custom animations, glassmorphism, scroll reveals, responsive grid
- **JavaScript** — Intersection Observer, animated counters, accordion FAQ, pricing toggle, parallax
- **Fonts** — Inter (UI), JetBrains Mono (data) via Google Fonts

## How to View
